# Local notes for AI agents

Feel free to use this directory for private local scratch work, notes, plans,
and experiments. Using it is optional; there is no required format or upkeep.

Only this README is tracked. Everything else in this directory, including
subdirectories and their README files, is ignored by Git. Ignoring files is not
a security guarantee: do not store credentials or other secrets here.

Move findings that should be shared into the appropriate project documentation
or source code.
